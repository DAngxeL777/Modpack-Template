## 🎯 О проекте

**Modpack-Template's** — это универсальный шаблон структуры модпака для **NeoForge и Fabric** на версиях **1.20.1 – 1.21.1**.

Главная боль сборщиков — хаос в папке `Mods`. Сотня `.jar` в одной куче, потерянные конфиги, забытые квесты.  
Этот шаблон решает проблему: чёткая категоризация модов (`00–07`), отдельные папки для конфигов и квестов, TODO-система для недоделанного.

Подходит для:
- 🧑‍💻 Одиночных сборщиков, уставших от бардака
- 👥 Команд, работающих над одним паком
- 🚀 Новичков, которые хотят сразу делать правильно
- 🏭 Тех, кто собирает паки серийно и хочет стандартизации

## 🧩 Поддерживаемые версии и загрузчики

| Загрузчик | 1.20.1 | 1.21.1 |
|-----------|:------:|:------:|
| **NeoForge** | ✅ 47.x | ✅ 21.1.x |
| **Fabric** | ✅ 0.16.x | ✅ 0.16.x |

> 💡 Структура не зависит от загрузчика — она одинаково работает и на NeoForge, и на Fabric. Меняются только моды внутри категорий.

## 📁 Структура

```text
Modpack/
├── 📂 Config/                  # Конфиги модов
│   ├── 📂 Готовые/             # Уже настроенные
│   └── 📂 Сделать/             # TODO: что ещё настроить
│
├── 📂 Mods/                    # Моды, разбитые по категориям
│   ├── 📂 00 - Optimization/   # Оптимизация и производительность
│   ├── 📂 01 - Util's/         # Утилиты (JEI, Jade, ...)
│   ├── 📂 02 - Control's/      # Управление и интерфейс
│   ├── 📂 03 - Visual's/       # Визуал, шейдеры, анимации
│   ├── 📂 04 - System's/       # Крупные механики (Create, AE2, ...)
│   ├── 📂 05 - Mob's/          # Мобы и существа
│   ├── 📂 06 - Generation's/   # Генерация мира
│   └── 📂 07 - Dev/            # Инструменты разработчика
│
├── 📂 Quest/                   # Квесты (FTB Quests / Better Questing)
└── 📄 Readme.md
